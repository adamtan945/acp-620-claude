3 分鐘速覽

三種 board，差在工作節奏

  1. Scrum＝sprint 節奏固定週期承諾一批工作；sprint 還沒開始時 board 是空的。
  2. Kanban＝連續流隨時拉新工作，靠 WIP limit 控制；只有 Control chart 與 CFD 兩張報表。
  3. Kanban with backlog 不是第三種類型是在 Kanban board 開 Kanban backlog：把一個 status 拖進 Kanban backlog 面板。
  4. Board 不能 Scrum ↔ Kanban 互轉要換就用同一份 filter 再建一個。
  5. Done 怎麼清Scrum＝Complete sprint；CMP Kanban＝Release 或 Hide completed；TMP Kanban＝14 天自動清或手動 Clear Done。
  6. Parallel sprints你常錯Jira admin 在 Jira configuration 開；一次只能完成一個 sprint；Velocity 不分團隊。
  7. 一個 board 最多 5,000 張超過的不會顯示，要縮小 filter。

Kanban backlog

怎麼開、誰能開

  • 開了之後 Backlog 畫面顯示兩段：Backlog（對到 backlog 欄的 status）與下一段（board 第一欄）。
  • 所有 status 都塞在第一欄時，Backlog 段會是空的。
  • 在 Backlog 可以排 rank、用 Epic panel、bulk edit。
自我檢查：先在心裡回答，再點開對答案
Q1開了 Kanban backlog，Backlog 段卻永遠是空的，為什麼？看答案
沒有任何 status 對到 Kanban backlog 那一欄（例如全部 status 都放在第一欄）。
本段必考
  • 開法：Board settings → Columns，把 status 拖進 Kanban backlog 面板。
  • 誰能開：board admin 或 project admin。
清掉完成的卡

Done 欄太長怎麼辦

情境怎麼清誰能做
CMP ScrumComplete sprint：最右欄的 issue 算完成，清出 board，不回 backlog有 Manage Sprints 的人（Jira admin 不需要）
CMP KanbanRelease 版本（sub-filter 藏掉已 release 的）；或 Hide completed work（1／2／4 週）Manage Versions／board admin
TMP Kanban（沒開 Sprints）移到 Done 後 14 天自動清；或 Done 欄 ••• → Clear Donespace admin、Jira admin
TMP（開了 Sprints）不能手動清；完成 sprint 時清—
清掉不是刪除

TMP 清 parent 時，底下的 sub-task 不管完成與否都一起從 board 消失；但資料還在，See all Done work items 找得回來。

自我檢查：先在心裡回答，再點開對答案
Q1CMP Kanban 的 Done 欄堆了兩個月，要怎麼清？看答案
Release 版本（預設 sub-filter 會藏掉已 release 的），或調 Hide completed work items older than（1／2／4 週）。
Q2TMP 的 Kanban，上週 Done 的卡片自己不見了，是 bug 嗎？看答案
不是。沒開 Sprints 的 TMP，Done 超過 14 天自動從 board 清掉，資料還在。
本段必考
  • Scrum：Complete sprint。
  • CMP Kanban：Release 或 Hide completed（1／2／4 週）。
  • TMP：14 天自動清；開了 Sprints 就不能手動清。
Parallel sprints

同一個 backlog、多個 active sprint

項目重點
誰開、在哪開Jira admin（Administer Jira）：⚙ Settings → Jira apps → Jira configuration → Parallel sprints
完成 sprint一次只能完成一個：先在 Active sprints 選一個 sprint，Complete 按鈕才會出現
Velocity照樣每個 sprint 一組長條，但不分團隊；官方假設各團隊估算方式相同
同一張 issue只能在一個 active sprint
TMP也支援（JSWCLOUD-17195 已 Fixed），但啟用路徑不同
你練習時錯過

「Velocity 不能分開顯示每個 sprint」是錯的；它本來就一個 sprint 一組長條。真正的限制是不分團隊。「可以一次完成所有 active sprint」也是錯的。

自我檢查：先在心裡回答，再點開對答案
Q1Parallel sprints 開了以後，可以一次把所有 active sprint 都完成嗎？看答案
不行。要先選一個 sprint 才會出現 Complete Sprint，一次完成一個。
本段必考
  • 開關：Jira admin，Jira configuration。
  • 一次完成一個 sprint。你常錯
  • Velocity 每個 sprint 一組長條，但不分團隊。你常錯
