3 分鐘速覽

Layout 管「顯示在哪」，權限管「改不改得了」

  1. Layout 三個區Description fields、Context fields（Details 與分隔線下的 More fields）、Hidden。
  2. Project admin 排位置，Jira admin 決定有哪些欄位新欄位要 Jira admin 建並放上 screen；screen 被共用時 project admin 改不了 layout。
  3. 看得到 ≠ 改得了Assignee 要 Assign Issues、Reporter 要 Modify Reporter、Due date 要 Schedule Issues。
  4. TMP 的 admin 可以自己加欄位考試版：TMP 沒有 screen scheme；現行 transition 可用 Request input 顯示畫面。
