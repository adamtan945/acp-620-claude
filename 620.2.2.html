跨團隊、跨 project 的 board

一個 board 可以看多個 project，一個 project 也能有多個 board，因為 board 的內容由 saved filter 決定。

3 分鐘速覽

Board 跟著 filter 走，不跟著 project 走

  1. 跨 project board＝一份跨 project 的 saved filterproject in (A, B, C) ORDER BY Rank ASC，再用它建 board。
  2. 誰看得到 board＝誰看得到 filterboard 沒有自己的分享設定；卡片再依各自的 Browse Projects 顯示。
  3. Copy board 沿用同一份 filter你常錯改副本的 filter 查詢，原 board 也會變；要脫鉤就 Save as 另存新 filter。
  4. Location 只決定 board 掛在哪哪個 project 的側欄、哪個 project admin 能管；不影響顯示哪些 issue。
  5. 跨 project 會打架的Version 不能跨 project；sprint 跨 project 要每個 project 的 Manage Sprints；估算方式整個 board 一種。
  6. Simplified workflow 只給單一 project board跨 project board 不能在 board 上直接加 status。

複製 board：副本沿用同一份 filter

項目官方明說的
資料範圍副本用同一份 filter，不會自動產生新 filter
管理權執行複製的人是副本的 administrator
Filter 編輯權filter 不是你建的，可能改不動
你問過的

只缺 global permission「Create shared objects」（Share dashboards and filters），還能複製嗎？依官方原文推論：可以（9/26 另一份練習題也以此為正解，它的解析引用 Atlassian 權限說明：從 Boards 頁新建 board 要有 Create Shared Objects 才分享得出去；但建立 project 時自動產生、首次設定 Jira Software、複製 board 這三種不需要，複製的 board 會分享給和原 board 相同的使用者）。副本沿用已分享的同一份 filter，沒有新建或分享任何東西，所以團隊照樣看得到、能用。真正需要這個權限的是下一步：另存新 filter 並分享給團隊。（官方未明寫權限前提，待實測）

動手做

實作 Lab：建一個跨 project board，再複製它

約 25 分鐘你（建 filter、建 board）；Leo 的瀏覽器

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：用一份 saved filter 建出看得到 WEB 與 OPS 的 board，從 Leo 的視角看「兩道門」，再複製 board 看副本和原 board 共用同一份 filter。

這個 Lab 對應的考點

Board 內容由 saved filter 決定；看得到 board＝filter 有分享，看得到卡片＝有該 project 的 Browse Projects；Copy board 沿用同一份 filter。

步驟

  1. 你應該看到：Filters 列表出現 WEB+OPS，owner 是你，只有你看得到。
  2. 你應該看到：Board 上同時有 WEB 與 OPS 的卡片。
  3. 你應該看到：Leo 通常打不開或看不到卡片：filter 沒分享給他，board 對他來說不存在。
  4. 你應該看到：Leo 看得到 board 與 WEB 的卡片；OPS 的卡片要看 Leo 在 OPS 有沒有 Browse Projects（Leo 不是 OPS 成員，若 OPS 的 permission scheme 沒把 Browse 給所有登入者，他就看不到 OPS 的卡）。
  5. 你應該看到：Location 是 WEB；Saved filter 是 WEB+OPS。兩個是分開的設定：一個決定掛在哪，一個決定顯示什麼。
  6. 你應該看到：副本的 Saved filter 仍是 WEB+OPS，不是新的 filter；你是副本的 administrator。
  7. 你應該看到：原 board 也只剩 Bug：兩張 board 共用同一份 filter，改一份等於兩張一起變。
  8. 你應該看到：Board 分成 WEB、OPS 兩條 swimlane。

試試看：改一個設定，觀察差異

T1在副本那邊：開 WEB+OPS filter → Save 旁的下拉 → Save as 存成 WEB+OPS bugs，再到副本的 General 把 Saved filter 換成它；然後把 WEB+OPS 的 AND type = Bug 拿掉。看結果
原 board 恢復全部 issue，副本只看 Bug。要讓副本脫鉤，就是另存新 filter 再指過去。
T2在 WEB+OPS board 打開一張 OPS 的 issue，看 Fix versions 可以選哪些 version。看結果
只能選 OPS 自己的 version：version 屬於各自的 project，跨 project board 也不能共用。
T3把 WEB+OPS board 的 Location 改成你的個人 profile，再看 WEB 的側欄與 board 內容。看結果
WEB 側欄的 board 清單少了它，但 board 上的卡片完全沒變：location 只決定掛在哪。
心像錨點：閉上眼睛想一次這個畫面

兩張 board 的 General 頁並排：Saved filter 欄位寫著同一個名字 WEB+OPS。改一份，兩張一起變。口訣：Copy board 不 copy filter。

收尾

  • 刪除副本 board 與 WEB+OPS bugs filter。
  • 把 WEB+OPS 的查詢還原成 project in (WEB, OPS) ORDER BY Rank ASC，location 改回 WEB。
  • 保留 WEB+OPS board 與 filter（分享給 WEB）：620.2.4、620.2.7 的 Lab 會再用。
