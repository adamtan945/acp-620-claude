620.2.2・Board configuration 29%

跨團隊、跨 project 的 board

一個 board 可以看多個 project，一個 project 也能有多個 board，因為 board 的內容由 saved filter 決定。

你問過：Copy board考試佔 29%

  • Understand the implications of cross-project boards跨 project board 的影響
  • Understand which board configurations support cross-project boards哪些 board 設定支援跨 project

3 分鐘速覽

Board 跟著 filter 走，不跟著 project 走

  1. 跨 project board＝一份跨 project 的 saved filterproject in (A, B, C) ORDER BY Rank ASC，再用它建 board。
  2. 誰看得到 board＝誰看得到 filterboard 沒有自己的分享設定；卡片再依各自的 Browse Projects 顯示。
  3. Copy board 沿用同一份 filter你常錯改副本的 filter 查詢，原 board 也會變；要脫鉤就 Save as 另存新 filter。
  4. Location 只決定 board 掛在哪哪個 project 的側欄、哪個 project admin 能管；不影響顯示哪些 issue。
  5. 跨 project 會打架的Version 不能跨 project；sprint 跨 project 要每個 project 的 Manage Sprints；估算方式整個 board 一種。
  6. Simplified workflow 只給單一 project board跨 project board 不能在 board 上直接加 status。

複製 board：副本沿用同一份 filter

項目官方明說的
資料範圍副本用同一份 filter，不會自動產生新 filter
管理權執行複製的人是副本的 administrator
Filter 編輯權filter 不是你建的，可能改不動
你問過的

只缺 global permission「Create shared objects」（Share dashboards and filters），還能複製嗎？依官方原文推論：可以（9/26 另一份練習題也以此為正解，它的解析引用 Atlassian 權限說明：從 Boards 頁新建 board 要有 Create Shared Objects 才分享得出去；但建立 project 時自動產生、首次設定 Jira Software、複製 board 這三種不需要，複製的 board 會分享給和原 board 相同的使用者）。副本沿用已分享的同一份 filter，沒有新建或分享任何東西，所以團隊照樣看得到、能用。真正需要這個權限的是下一步：另存新 filter 並分享給團隊。（官方未明寫權限前提，待實測）

  • 要獨立範圍：Save as 新 filter 再指定給副本。
Board location

掛在 project 或個人 profile

  • Location 掛在已停用的 project 或已刪除的使用者 → board 找不到，要重新指定。
  • Project admin 只能管 location 在自己 project 的 board。
本段必考
  • Location＝放哪、誰管；filter＝顯示什麼。

設定跨 project要注意
Filter✓JQL 結尾要 ORDER BY Rank，否則拖不動
Columns✓每個 project 的「完成」status 都要對到最右欄
Swimlanes✓有「Projects」選項，一個 project 一條
Sprints◐ 有代價改 sprint 需要每個相關 project 的 Manage Sprints
Versions✗version 屬於各自 project，不能共用
Estimation◐ 一種整個 board 一種估算方式，兩團隊尺度要一致

排序（Rank）✓要對該 issue 有 Schedule Issues＋Edit Issues

易錯觀念

考題愛用的錯誤說法

複製 board 後，只有複製的人是副本的 board administrator。
副本沿用原 board 的設定（含 admin 名單），再加上複製的人：原 admin（Olivia）＋你＝兩位。官方只說 you'll be the administrator，沒說唯一。
複製只要看得到原 filter，不用能編輯；filter 共用同一份。
你練習時錯過官方來源
跨 project 的 board 可以把 A 的 issue 拖進 B 的 version，也能在 Kanban 設 estimation。
Epic 可以跨 project、version 不行（Fix version 只能選自己 project 的）；Releases 頁一次只看一個 project；Estimation 設定只有 Scrum board 有。能做的：跨 project 排序、把 A 的 issue 拖進 B 的 epic。

Board 內容由 saved filter 決定；location 只決定掛在哪。
