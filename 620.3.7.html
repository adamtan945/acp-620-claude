3 分鐘速覽

每個功能都是三道關卡

  1. 全域開關 × project 權限 × 畫面入口三道都過才用得到：例如 issue linking 關了，有 Link Issues 也沒用。
  2. Time trackingWork On Issues 記工時；Time tracking 欄位要在 screen 上；三個欄位 Original、Remaining、Time spent。
  3. Issue link 有方向Blocks／is blocked by；跨 project 兩邊都要 Link Issues。
  4. @提及看不到人缺全域 Browse users and groups：只看得到同 project 的人。
  5. Watcher幫別人加要 Manage Watchers；看清單要 View Voters and Watchers。
  6. 附件Create／Delete Own／Delete All Attachments 三個權限；單檔上限預設 1 GB、最大 2 GB。
  7. Smart commitscommit 訊息寫 MOB-10 #comment、#time 2h、#resolve；key 要在 branch、commit 或 PR 標題。

核心模型

三道關卡

Time tracking 放在第一道全域開關是考試版的說法（Jira admin 可以在全站設定啟用或停用）。現行版官方寫 Jira Cloud 的 time tracking 一律啟用，不能整個關掉；要不要用改由 field configuration 顯示或隱藏 Time tracking 欄位決定，所以對 time tracking 來說，現行版的第一道關卡其實落在欄位設定上。

Time tracking

記工時

關卡內容
全域⚙ → Issues → Time tracking：每日工時（預設 8）、每週工作天（預設 5）、格式與單位
權限Work On Issues；Edit／Delete Own／All Worklogs 各自獨立
欄位Time tracking 欄位放上 create／edit screen
Status 限制jira.permission.work.denied 可以讓某個狀態不能記工時
工時權限能做什麼
Work On Issues新增工時紀錄（log work），記時可調整 Remaining Estimate
Edit Own Worklogs改自己的工時紀錄
Edit All Worklogs改任何人的工時紀錄
Delete Own Worklogs刪自己的工時紀錄
Delete All Worklogs刪任何人的工時紀錄
Edit Issues改 Original Estimate（一般欄位）
你問過的：Work On Issues 能做什麼？

Work On 只管新增；改、刪工時各分 Own 和 All。官方：allows users to log time using the time tracking field。

  • 只有 Work On Issues：能記、不能改或刪自己記錯的紀錄。
  • 前提：time tracking 開著、欄位在畫面上、看得到 issue（Browse）。

動手做

實作 Lab：記工時、連 issue、加附件

約 25 分鐘Jira admin（全域設定、scheme）；Leo、Kim 的瀏覽器

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：走一次「全域開關 → project 權限 → 畫面入口」三道關卡：記工時、建 issue link、加與刪附件、@提及與 watch。

這個 Lab 對應的考點

每個功能三道關卡：全域開關、project 權限、欄位在畫面上；Work On Issues 只管新增工時，改、刪各分 Own／All；跨 project 連結兩邊都要 Link Issues；附件上傳與刪除是不同權限。

準備

  • WEB 有兩張未完成的 story（例如 WEB-1、WEB-2）。

步驟

  1. 你應該看到：看得到每日工時、每週工作天、顯示格式與預設單位這些全站設定。
  2. 你應該看到：Time tracking 欄位顯示已記的時間與剩餘時間；Work log 出現 Leo 的紀錄。
  3. 你應該看到：Leo 能記工時卻刪不掉自己的紀錄：Work On Issues 只管新增，刪除要 Delete Own／All Worklogs。
  4. 你應該看到：Link type 由 Jira admin 定義，有方向。
  5. 你應該看到：WEB-2 顯示 is blocked by WEB-1：同一條連結，兩端看到的描述相反。
  6. 你應該看到：Kim 通常看不到刪除（垃圾桶）圖示：刪別人的附件要 Delete All Attachments。
  7. 你應該看到：能不能在名單裡找到 Ana，取決於 Leo 有沒有全域 Browse users and groups（Ana 不在 WEB）；按 W 會切換 watch。

試試看：改一個設定，觀察差異

T1在 Work item linking 頁按 Deactivate，Leo 重新整理 WEB-1 找 Link 的選項，然後立刻 Activate。看結果
關掉時 Leo 有 Link Issues 也連不了：全域開關是第一道關卡。這是全站設定，做完馬上打開。
T2⚙ Settings›System›Attachments：只看 Attachment Size。看結果
看得到單檔大小上限設定；官方預設 1 GB、最大可設 2 GB。
T3（站台有連 Bitbucket 或 GitHub 才做；否則想像）commit 訊息寫 WEB-1 #comment 修好轉址 #time 30m 並 push。看結果
WEB-1 出現留言與 30 分鐘工時，Development 面板出現 commit；commit email 對不到唯一的 Jira 使用者或沒權限時，指令不會生效。
心像錨點：閉上眼睛想一次這個畫面

WEB-2 的 Linked work items 區塊寫著 is blocked by WEB-1；Work log 裡 Leo 那一筆沒有 Delete。口訣：開關、權限、畫面，三道都要過。

收尾

  • 把 Delete Own Worklogs 改回原樣；確認 Work item linking 是 ON。
  • 刪除 Lab 用的 link、附件與工時紀錄（用你的帳號）。

  • Delete an attachment in a work itemOnly you or an admin can delete attachments that you've added (unless your permissions have been turned off).
