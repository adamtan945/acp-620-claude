3 分鐘速覽

每個功能都是三道關卡

  1. 全域開關 × project 權限 × 畫面入口三道都過才用得到：例如 issue linking 關了，有 Link Issues 也沒用。
  2. Time trackingWork On Issues 記工時；Time tracking 欄位要在 screen 上；三個欄位 Original、Remaining、Time spent。
  3. Issue link 有方向Blocks／is blocked by；跨 project 兩邊都要 Link Issues。
  4. @提及看不到人缺全域 Browse users and groups：只看得到同 project 的人。
  5. Watcher幫別人加要 Manage Watchers；看清單要 View Voters and Watchers。
  6. 附件Create／Delete Own／Delete All Attachments 三個權限；單檔上限預設 1 GB、最大 2 GB。
  7. Smart commitscommit 訊息寫 MOB-10 #comment、#time 2h、#resolve；key 要在 branch、commit 或 PR 標題。

Time tracking

記工時

關卡內容
全域⚙ → Issues → Time tracking：每日工時（預設 8）、每週工作天（預設 5）、格式與單位
權限Work On Issues；Edit／Delete Own／All Worklogs 各自獨立
欄位Time tracking 欄位放上 create／edit screen
Status 限制jira.permission.work.denied 可以讓某個狀態不能記工時
本段必考
  • 記工時＝Work On Issues＋欄位在 screen。
連結

Issue link、web link、Confluence page

種類特性
Issue link有方向、可用 JQL 查；link type 由 Jira admin 定義
Web link指向外部網址、沒有方向
Confluence pageJira 要先和 Confluence 連結；epic 可從 Related work 連
本段必考
  • 要表達先後關係用 issue link（Blocks）。
@mention、watch、附件

通知與附件

  • @提及：缺 Browse users and groups → 只看得到同 project 有 Browse 的人。
  • Watch：快捷鍵 W；幫別人加要 Manage Watchers。
  • 附件：拖曳、Add、貼上；檔名不能有 \ / " % : $ ? *。
  • 上傳得了 ≠ 刪得掉：Delete Own／All Attachments 是另外的權限。
本段必考
  • @ 找不到人 → Browse users and groups。
  • 附件三權限各自獨立。
Bitbucket

開發資訊與 smart commits

指令範例
留言MOB-10 #comment 修好轉址
記工時MOB-10 #time 2h 重構登入
轉狀態MOB-10 #resolve
  • Issue key 要出現在 branch 名、commit 訊息或 PR 標題。
  • Smart commit 不生效：commit email 對不到唯一的 Jira 使用者、該使用者沒權限、或 transition 有必填欄位。
  • 看 Development 面板需要 View Development Tools。
本段必考
  • Issue key 是唯一的膠水。
  • Smart commit 用的是 commit 作者的權限。
