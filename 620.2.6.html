Swimlanes、卡片、工作日

同一個需求常有三種手段：分組（swimlane）、上色（card color）、顯示欄位（card layout）。Working days 決定哪些報表跳過假日。

3 分鐘速覽

分組、上色、顯示欄位、工作日

  1. Swimlane＝分組（改位置）Queries、Stories、Assignees、Epics、Projects、No swimlanes；Queries 是由上而下第一個符合的贏。
  2. Card color＝上色（不改位置）Issue types、Priorities、Assignees、Queries、None；沒有「依 status」選項，但可用 Queries 寫。
  3. Card layout＝在卡片上多顯示最多 3 個欄位Scrum 可分別設 backlog 與 active sprint。
  4. Working days 每個 board 各自設定Board admin 或 location 所在 project 的 admin；可設每週工作日、非工作日、時區。
  5. 吃 working days：5 張報表＋2 個 gadget你常錯Burndown、Sprint、Epic、Version report、Control chart；Sprint Health、Burndown gadget。

  • TMP：只能在 View settings 顯示／隱藏既有欄位（每人各自），不能自選加欄位。

動手做

實作 Lab：Swimlane、卡片顏色與工作日

約 20 分鐘WEB 的 board admin 或 project admin

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：在 WEB board 切換 swimlane 與 card color，加卡片欄位，再設一個非工作日，分清「改位置、改外觀、改報表」三件事。

這個 Lab 對應的考點

Swimlane 改位置、card color 只改左緣色條、card layout 最多加 3 個欄位；working days 每個 board 各自設定，影響 Burndown、Sprint、Epic、Version report、Control chart 與兩個 gadget。

準備

  • WEB 的 active sprint 裡有一張 priority = Blocker 的 Bug。
  • 若 WEB 已換成新版 board view，card layout 與 Days in column 改在 board 的 View settings。

步驟

  1. 你應該看到：預設有 Expedite（priority = Blocker）與 Everything Else；Everything Else 在最下面、沒有刪除鍵。
  2. 你應該看到：它在 Expedite，不在 Bugs。
  3. 你應該看到：那張 Blocker Bug 改到 Bugs 這條：排在上面的 lane 先拿走 issue。
  4. 你應該看到：Assignees：一人一條；Stories：一張 parent 一條，sub-task 排在底下。
  5. 你應該看到：In Progress 的卡左緣出現紅色細條，卡片位置不變。下拉的方法只有 work types、priorities、assignees、queries 等，沒有 Status、Epic、Reporter。
  6. 你應該看到：卡片上多了三個欄位；官方上限是 3 個額外欄位。
  7. 你應該看到：通常會看到灰色 guideline 在非工作日那天保持平的（官方 Sprint report 頁的說明）。

試試看：改一個設定，觀察差異

T1打開 WEB+OPS board（620.2.2 建的）的 Working days。看結果
沒有你剛加的非工作日：working days 是每個 board 各自設定。
T2打開 WEB 的 Velocity Chart 與 Cumulative Flow Diagram。看結果
沒有任何變化：它們不在官方「吃 working days」的清單裡。
T3只看不改：WEB›Space settings›Screens，展開 screen scheme，找 View work item screen。看結果
這裡決定 issue 詳細頁顯示哪些欄位；考綱時代叫 Issue detail view，現行由 screen 控制。
心像錨點：閉上眼睛想一次這個畫面

Board 上同一張 Blocker Bug：Bugs lane 一拖到 Expedite 上面，它就換到另一條。旁邊的卡左緣多了一條紅線，但沒有移動。口訣：swimlane 搬家，card color 換衣服。

收尾

  • Swimlanes 改回步驟 1 記下的方法；刪除 Bugs 這條 query。
  • Card colors 改回原本的方法、刪除測試 query；Card layout 移除三個測試欄位。
  • Working days 移除明天的非工作日。
