620.2.6・Board configuration 29%

Swimlanes、卡片、工作日

同一個需求常有三種手段：分組（swimlane）、上色（card color）、顯示欄位（card layout）。Working days 決定哪些報表跳過假日。

你問過：working days考試佔 29%

3 分鐘速覽

分組、上色、顯示欄位、工作日

  1. Swimlane＝分組（改位置）Queries、Stories、Assignees、Epics、Projects、No swimlanes；Queries 是由上而下第一個符合的贏。
  2. Card color＝上色（不改位置）Issue types、Priorities、Assignees、Queries、None；沒有「依 status」選項，但可用 Queries 寫。
  3. Card layout＝在卡片上多顯示最多 3 個欄位Scrum 可分別設 backlog 與 active sprint。
  4. Working days 每個 board 各自設定Board admin 或 location 所在 project 的 admin；可設每週工作日、非工作日、時區。
  5. 吃 working days：5 張報表＋2 個 gadget你常錯Burndown、Sprint、Epic、Version report、Control chart；Sprint Health、Burndown gadget。

Card colors 與 layout

上色與卡片欄位

  • Card layout：每張卡最多再加 3 個欄位；Scrum 的 backlog 與 active sprint 可分開設。
  • Days in column：卡片上的小點表示在這欄待了幾天。
  • TMP：只能在 View settings 顯示／隱藏既有欄位（每人各自），不能自選加欄位。
本段必考
  • Card color 五種依據；status 用 Queries。
  • Card layout 最多加 3 個欄位（CMP）。

Issue detail view

點開卡片右側看到什麼

  • Summary 一定顯示；Description 不能從預設版面刪除，但官方註明它可以依 field scheme 被隱藏。
  • 考綱的 Issue detail view 原本是 Board settings 的一頁；現行文件改由 Project settings → Screens 的 View issue screen 控制。
  • 考試問「誰管」→ board admin／project admin。

  • 現行：由 View issue screen 控制。
