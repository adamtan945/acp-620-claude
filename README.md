# ACP-620 繁體中文教材（v2）

Atlassian **ACP-620 Managing Jira Projects for Cloud** 認證的完整中文教材：24 節逐節講解 + 463 題題庫（單選、多選、圖例題）+ 63 題計時模擬考。

線上閱讀：<https://adamtan945.github.io/acp-620-claude/>

## 內容

- **24 節**對應官方 Detailed Exam Topics（V2）：每節都是「3 分鐘速覽 → 心智圖 → 分段講解（自我檢查、本段必考）→ 易錯觀念 → 題目關鍵字 → 一分鐘腦內整理 → 本節練習」。
- **463 題題庫**：單選、多選、圖例題；每次作答都記錄，可標記「不懂」、錯題重練、全真 63 題模擬考。紀錄存在瀏覽器，可匯出匯入。
- **報表與 gadget 圖鑑**、**考前速讀**、**易錯與易混**：由各節內容自動彙整。
- 手機、平板、桌機都能閱讀；淺色與深色模式。

## 關於內容正確性

- 考試沿用 project／issue 等舊用語，現行 Jira Cloud 已改為 space／work item；教材以考試用語為主。
- 官方文件改版與考綱不同之處兩版並陳，並標明作答依據；未明載的行為標示為推論或實機驗證。
