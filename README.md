# ACP-620 繁體中文教材

Atlassian **ACP-620 Managing Jira Projects for Cloud** 認證的完整中文教材：24 節逐節講解 + 309 題題庫 + 63 題計時模擬考。

線上閱讀：<https://adamtan945.github.io/acp-620-claude/>

## 內容

- **24 節**對應官方 Detailed Exam Topics（V2 / March 2023）的每一個小節，每節都精讀該節列出的官方文件後撰寫，頁尾附實際讀過的來源連結。
- **309 題題庫**（四選一，每題四段逐選項解析與官方來源），依考試比重分佈：620.1 專案建立 13%、620.2 board 設定 29%、620.3 專案管理 25%、620.4 自動化 14%、620.5 報表 19%。
- **模擬考**：依比重隨機抽 63 題、計時 180 分鐘、交卷後逐題回顧與錯題複習，也可只練單一 domain。作答紀錄存在瀏覽器本機。
- **互動圖解**：權限加總計算器、column↔status 連動、issue type 對應 scheme、board 三層過濾漏斗、自動指派決策等。
- 深色模式跟隨系統，可手動切換；支援 `prefers-reduced-motion`。

## 使用方式

直接開 `index.html` 即可，純靜態、相對路徑、無外部資源，離線也能用。

## 關於內容正確性

- 考試沿用 **project／issue** 等舊用語，現行 Jira Cloud 已改為 **space／work item**；教材以考試用語為主，引用現行官方文件時保留其用語。
- 官方文件在 2025–2026 改版而與 2023 考綱不同之處（例如 time tracking 已永遠啟用、automation 用量改以步驟計），教材**兩版並陳**並標明作答應以哪一版為準。
- 官方文件未明確載明的行為，標示為「官方未明列／實機驗證」，不寫成通則。
