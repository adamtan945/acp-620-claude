3 分鐘速覽

Dashboard 只考兩件事：誰能做什麼、該放哪個 gadget

  1. 每個 gadget 都要接資料來源大多接 filter 或 project；Sprint 三個接 board；Assigned to Me 這類個人 gadget 不用設定。
  2. 任何人都能建 dashboard要分享出去才需要 global permission「Share dashboards and filters」。
  3. 分享 dashboard ≠ 分享資料同事打開一片空白 → 底層 filter 沒分享給他，或他沒有 Browse Projects。
  4. 一維 vs 二維Pie Chart、Issue Statistics 一次只能一個欄位；「每個人各狀態幾張」要用 Two Dimensional Filter Statistics。
  5. Sprint 三兄弟接 boardSprint Health（進度條＋數字）、Sprint Burndown（曲線）、Days Remaining（一個數字）。
  6. 刪掉的 dashboard 只有 Jira admin 救得回丟進 trash 60 天後永久刪除；System dashboard 也只有 Jira admin 能改。
  7. 吃 working days 的 gadget 只有兩個你常錯Sprint Health 和 Burndown gadget。
  8. Road Map gadget你常錯列出未來 N 天要 release 的版本和各版本進度；單一版本的預測日要看 Version report。

操作面

建立、分享、刪除、還原

動作規則
建立任何 Jira 使用者都能建立（Dashboards → Create dashboard）。
版面Edit → Change layout：單欄、兩欄（等寬或左寬）、三欄。
分享分別設 Viewers 與 Editors，對象可以是 user、group、project、project role、任何登入者或 public。需要 global permission Share dashboards and filters。
複製••• → Copy dashboard，以既有的為底建新的。
自動刷新••• → Configure automatic refresh，以分鐘為單位。
Wallboard單一 dashboard 全螢幕；slideshow 可以輪播多張、設定秒數。
刪除與還原Move to trash；只有 Jira admin 能還原，60 天後永久刪除。
System dashboard登入後預設看到的那一張，只有 Jira admin 能改，改了影響所有人。
自我檢查：先在心裡回答，再點開對答案
Q1誤把 dashboard 丟進 trash，擁有者自己能還原嗎？看答案
不能。只有 Jira admin 能還原，60 天後永久刪除。
Q2Project admin 建好 dashboard，分享時選不到 project role，缺什麼？看答案
缺 global permission Share dashboards and filters。建立不用權限，分享才需要。
本段必考
  • 建立：任何人；分享：要 Share dashboards and filters。
  • 還原：只有 Jira admin，60 天內。
  • System dashboard：只有 Jira admin 能改。

Gadget 圖鑑

每個 gadget 長什麼樣子

每一格：上面是示意圖，下面是資料來源、它在看什麼、最常考的一點。數字是示意用的假資料。

分佈與清單

Filter Results

來源：saved filter

把 filter 的結果列成清單，可自選欄位與筆數。

考點　不分組；內容由 filter 決定，不會自動換成「我的」issue，但仍受權限限制：filter 要分享給對方、對方也要有 Browse 權限才看得到。

Pie Chart

來源：filter 或 project

依一個欄位畫佔比圓餅。

考點　一次只能一個欄位，算張數。

Issue Statistics

來源：filter 或 project

一個欄位分組，列出數量與百分比。

考點　跟 Pie Chart 一樣是一維，只是用表格。

Two Dimensional Filter Statistics

來源：saved filter

兩個欄位交叉成表，例如 Assignee × Status。

考點　唯一能回答「每個人各狀態幾張」。

趨勢

Created vs Resolved

來源：filter 或 project

新建與解決兩條線，夾出紅／綠區；開 Cumulative totals 時兩條線是累計數。

考點　紅區＝backlog 在累積。

Recently Created Issues

來源：filter 或 project

每期新建幾張，綠＝已解決、紅＝未解決。

考點　看團隊跟不跟得上。

Average Age

來源：filter 或 project

未解決 issue 平均放了幾天。

考點　往上＝舊案堆積。

Resolution Time

來源：filter 或 project

已解決 issue 平均花幾天。

考點　Average Age 的反面。

Time Since Issues

來源：filter 或 project

依一個日期欄位畫每期張數。

考點　任何日期欄位都能選。

狀態停留

Average Time in Status

來源：filter 或 project

各狀態平均停留多久。

考點　找卡最久的狀態。

Average Number of Times in Status

來源：filter 或 project

平均進入每個狀態幾次。

考點　明顯大於 1＝反覆被退回。

個人（不用設定來源）

Assigned to Me

來源：不需設定

指派給觀看者、未完成的 issue。

考點　跨所有 project，內容跟著觀看者變。

Issues in Progress

來源：不需設定

指派給觀看者、狀態進行中的 issue。

考點　只列 In Progress，不含 To Do。

Watched／Voted Issues

來源：不需設定

觀看者關注或投過票的 issue。

考點　兩個 gadget，都跟著觀看者變。

Sprint（接 board）

Sprint Health

來源：board＋sprint吃 working days

依欄位上色的進度條，加 Time elapsed、Work complete、Scope change、Blockers、Flagged。

考點　看 scope change；吃 working days。

Sprint Burndown

來源：board＋sprint吃 working days

目前 sprint 的燃盡曲線。

考點　資料同 Burndown chart；吃 working days。

Days Remaining in Sprint

來源：board＋sprint

只顯示 sprint 還剩幾天。

考點　一個數字，適合掛牆上。

版本、project 與其他

Road Map

來源：project（可多選）

未來 N 天要 release 的版本與各版本的完成進度。

考點　多個版本的概覽；單一版本的預測日用 Version report。

Projects

來源：project

Project 資訊與常用 filter 捷徑。

考點　只是捷徑，不做統計。

Bubble Chart

來源：saved filter

四個維度：X＝開了幾天、Y＝留言數、泡泡大小＝參與人數或票數、顏色＝綠低紅高。

考點　撈出「又熱門又拖很久」的 issue。

Labels

來源：project

列出 project 用過的 label 與次數。

考點　檢查拼字變體。

Activity Stream

來源：project 或 user

最近的活動紀錄。

考點　純紀錄，不做統計。
同名的報表和 gadget
  • 報表和 gadget 各有一份、資料相同：Pie Chart、Created vs Resolved、Recently Created、Resolution Time、Average Age、Time Since
  • 報表在哪：project 的 Reports → More reports
  • Gadget 在哪：dashboard
  • 名字不同的一組：board 上的 Burndown chart，對應的 gadget 叫 Sprint Burndown
自我檢查：先在心裡回答，再點開對答案
Q1Sprint Health gadget 會顯示哪些數字？看答案
Time elapsed、Work complete、Scope change、Blockers、Flagged，加上一條依欄位上色的進度條。
Q2Average Time in Status 和 Average Number of Times in Status 差在哪？看答案
一個看停留多久，一個看進入幾次；次數明顯大於 1＝反覆被退回。
本段必考
  • Sprint Health：進度條＋5 個數字（含 scope change）。
  • Assigned to Me＝指派給我且未完成；Issues in Progress＝進行中的。
  • Average Age 看未解決；Resolution Time 看已解決。
易混組

五組最容易搞混的 gadget

這一組差在哪一點
Pie Chart／Issue Statistics／Two Dimensional／Filter Results前兩個一個欄位（Pie 畫圖、Statistics 列數字）；Two Dimensional 兩個欄位交叉；Filter Results 不分組直接列清單
Sprint Health／Sprint Burndown／Days Remaining都接 board＋sprint；Health 是進度條加數字、Burndown 是曲線、Days Remaining 只有一個數字
Assigned to Me／Issues in Progress／Filter Results前兩個不用設定、跟著觀看者變；Filter Results 要指定 filter，不會換成「我的」issue，但每個人只看得到自己有權限的
Average Time in Status／Average Number of Times in Status停留多久 vs 進入幾次
Average Age／Resolution Time未解決放多久 vs 已解決花多久
本段必考
  • 一維 vs 二維 vs 清單。
  • 跟著觀看者變的：Assigned to Me、Issues in Progress、Watched、Voted。
