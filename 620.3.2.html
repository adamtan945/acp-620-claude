3 分鐘速覽

Role 是佔位符：Jira admin 寫名字、project admin 填人

  1. 同一份 scheme，各 project 的人不同Scheme 寫「Developers 有 X 權限」，每個 project 的 admin 自己決定誰是 Developers。
  2. Project admin 能加人進 role，不能建 role建 role、設 default members 是 Jira admin（⚙ → System → Project roles）。
  3. Role 能用在哪你常錯Permission scheme、notification scheme、issue security level、workflow condition、分享 filter／dashboard。
  4. Role 不能用在哪你常錯全域權限、產品存取（只能 group）；filter subscription（只能自己或 group）。
  5. Default members 只套用到新 project既有 project 不會變。

操作

把人放進 role

  • 一個人可以同時有多個 role。
  • 外部協作者：請 admin 先邀請成 guest。
  • Project admin 可以把別人加成 Administrators。
本段必考
  • Project settings → People；project admin 就能做。
Role 的用途

能用在哪、不能用在哪

可以指定 project role

  • Permission scheme（例：Browse Projects）
  • Notification scheme 的收件人
  • Issue security level 的成員
  • Workflow condition
  • 分享 filter／dashboard 給某 project 的某 role

不能用 project role

  • 全域權限（只能 group）
  • 產品存取（只能 group）
  • Filter subscription（只能自己或 group）
你練習時錯過

「哪些可以關聯 project role」選：Dashboard sharing、Browse Projects（permission scheme）、Issue security levels。不選 filter subscription 與 global permissions。
