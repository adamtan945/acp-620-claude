怎麼用

每一節都是同一個讀法

  1. 3 分鐘速覽先讀編號重點，知道這一節考什麼。
  2. 看圖心智圖、流程圖、畫面示意。你沒實際操作過的功能，看畫面示意就知道設定在哪。
  3. 易錯觀念紅色 ✗ 是考題愛用的錯誤說法，綠色 ✓ 是正解。紅框是你練習時錯過的。
  4. 題目關鍵字 → 答案考試時看到這些字，直接聯想到答案。
  5. 本節練習單選、多選、圖例題都有；每次作答都會記錄，看不懂按星號「不懂」。

本教材為原創整理，非 Atlassian 官方出版品；題目皆為原創，不含第三方題庫題幹。考試沿用 project／issue 等舊用語，現行 Jira Cloud 已改為 space／work item。
