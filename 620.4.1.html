3 分鐘速覽

五種自動化手段，看觸發方式選

  1. Bulk change＝人手、一次最多 1,000 張；要全域 Make bulk changes＋動作對應的 project 權限。
  2. Post function＝每次 transition掛在 workflow；Jira admin 改；同步執行。
  3. Filter subscription＝按時寄清單不改 issue；訂給 group 要 Manage group filter subscriptions。
  4. Automation rule＝事件或排程Trigger → condition → action；project admin 能建單一 project 的 rule。
  5. Resolution 不能 bulk edit要走 bulk transition。
  6. Condition 藏按鈕、validator 擋提交、post function 事後做同一個 transition 的三個階段。

Filter subscription

按時寄出 filter 結果

  • Filter → Details → New subscription：收件人（自己或 group）、排程、空結果要不要寄。
  • 訂給 group 要全域 Manage group filter subscriptions。
  • 收件人只看到自己有權限的 issue。
  • 不能訂給 project role。
本段必考
  • Subscription 只通知不改 issue；不能訂給 project role。
