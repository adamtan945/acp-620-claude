3 分鐘速覽

五種自動化手段，看觸發方式選

  1. Bulk change＝人手、一次最多 1,000 張；要全域 Make bulk changes＋動作對應的 project 權限。
  2. Post function＝每次 transition掛在 workflow；Jira admin 改；同步執行。
  3. Filter subscription＝按時寄清單不改 issue；訂給 group 要 Manage group filter subscriptions。
  4. Automation rule＝事件或排程Trigger → condition → action；project admin 能建單一 project 的 rule。
  5. Resolution 不能 bulk edit要走 bulk transition。
  6. Condition 藏按鈕、validator 擋提交、post function 事後做同一個 transition 的三個階段。

易錯觀念

考題愛用的錯誤說法

Project admin 要在 workflow transition 時寄「自訂內容」的 email 給不同 group → 改 workflow 設定或 notification scheme。
用 automation rule：Work item transitioned trigger＋Send email（收件人可選 group、內容可自訂），project admin 就能建 single-project rule。Notification scheme 是 Jira admin 管、而且信件內容不能自訂；project admin 改 CMP workflow 只能在限制條件下加減 status／transition，post function 不歸他。
自訂 email＋project admin → automation；notification scheme＝Jira admin、內容固定。

動手做

實作 Lab：Bulk change 的邊界與 filter subscription

約 25 分鐘Jira admin（改 global permission）；另用 Leo

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：在 bulk change 精靈裡找出「跨 project 不能改的欄位」與「根本不能 bulk edit 的欄位」，再收回 Make bulk changes 看 Leo 的差別，最後替 filter 建一個訂閱。

這個 Lab 對應的考點

Bulk 要 global 的 Make bulk changes＋各 project 權限；最多 1,000 張；Components、Fix versions 要同一個 project；Resolution 要走 bulk transition；filter subscription 只能訂給自己或 group。

準備

  • 存一個 filter Lab open：project in (WEB, OPS) AND statusCategory != Done。

步驟

  1. 你應該看到：操作清單有 Edit、Move、Transition、Delete、Watch／Stop watching。
  2. 你應該看到：這兩項不能選（選到的 work item 跨了 WEB 與 OPS）；Change Priority、Change Due Date、Change Assign To 可以選。
  3. 你應該看到：Components、Fix versions 變成可選；清單裡仍然沒有 Summary、Description、Resolution 與 time tracking 欄位。
  4. 你應該看到：只能選同一個 workflow 的那一群；轉到完成狀態時要填 Resolution 這類必填值。看完按 Cancel，不必送出。
  5. 你應該看到：Leo 看不到或用不了 Bulk Change；他仍能一張一張編輯（那是 project 權限）。做完加回。
  6. 你應該看到：收件人只能選自己或 group，沒有 project role 可選。
  7. 你應該看到：看到幾條 essential post functions，不能刪、不能調順序；可以在它們之間插入自訂的 post function。

試試看：改一個設定，觀察差異

T1在 bulk change 選 Watch work items → Confirm，再打開其中一張的 Watchers。看結果
只有你自己被加進 watcher；bulk 沒有「把別人加成 watcher」的選項。
T2用 Leo 對 Lab open 建 subscription，收件人試著選 group。看結果
Leo 通常選不到 group：訂給 group 要 Manage group filter subscriptions 這個 global permission。
T3（想像，不實際做）把 WEB 的 work item bulk move 到 TEAM。看結果
Component 與 version 資料不會保留，而且移回來也救不回。
心像錨點：閉上眼睛想一次這個畫面

Bulk change 的 Edit 清單：Change Component/s 那一列灰掉，旁邊寫著要同一個 project。手、轉、時、事：bulk、post function、subscription、automation。

收尾

  • 確認 Make bulk changes 已加回原本的 group。
  • 刪除 Lab open 的 subscription；用 bulk Stop watching 取消剛才的 watch。
